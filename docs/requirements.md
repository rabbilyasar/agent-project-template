# Requirements

This document defines what the system must do.

Requirements are the product contract. Do not use this document as an implementation diary.

## Requirement Format

Use:

`REQ-<DOMAIN>-<NUMBER>`

Each requirement should contain:

- Requirement ID
- Title
- Requirement
- Acceptance Criteria
- Status

## Statuses

- Proposed
- Accepted
- In Progress
- Implemented
- Verified
- Deprecated
